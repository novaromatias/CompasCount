# Grill-Me (Entrevista Rápida y Directa)

Cuando el usuario invoque `/grill-me`, inicia de inmediato una entrevista interactiva usando la herramienta `ask_question`:

1. **Directo a las preguntas**: NO hagas maratones de lectura de código antes de preguntar. Formula la primera pregunta de inmediato basándote en la solicitud del usuario.
2. **Una sola pregunta a la vez**: Recorre el árbol de decisiones paso a paso.
3. **Recomendación clara**: Cada pregunta debe incluir la opción recomendada al inicio con `(Recomendado)`.
4. **Respeta las respuestas**: Una vez que el usuario elige una opción, avanza a la siguiente rama o procede a la implementación sin dar rodeos.
